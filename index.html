Como obtener tu token de solo lectura

1
Ve a Lighter y abre tokens

Accede a app.lighter.xyz/read-only-tokens con tu wallet conectada.

2
Crea un token de solo lectura

Clic en "Create token" → tipo all → expiracion larga (1 ano o mas) → confirma con tu wallet.

3
Copia el token y pegalo abajo

Formato: ro:123:all:1780000000:abc123... — solo se muestra una vez.

- Pega tu token ro:... para empezar.
Seguridad
Token de solo lectura: no permite trades ni retiradas. Datos guardados solo en este navegador.
